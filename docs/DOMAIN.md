# DOMAIN

Пользователь создаёт привычки, отмечает их выполнение и отслеживает прогресс целей. Проект представляет собой Telegram-бота, который помогает формировать регулярное поведение и контролировать достижение результата.

## Зачем нужен этот документ

Этот документ объясняет, **с какими сущностями работает модуль** и **какую задачу он решает**. По нему можно понять смысл кода ещё до чтения реализации.

## Что считается входными данными

Пользователь отправляет команды через Telegram. Каждая команда содержит название привычки или цели и опциональные параметры (целевое значение, дедлайн, прогресс).

## Основные сущности

**Привычка (Habit):** Правило, которое пользователь обязуется выполнять регулярно. Содержит название и периодичность. Не имеет состояния «завершена» — она либо есть, либо её нет. Примеры: «Читать 30 минут», «Зарядка утром».

**Отметка выполнения (Completion):** Факт выполнения привычки в конкретную дату. Неизменяема после создания. Несколько отметок образуют историю, по которой вычисляется streak (серия дней подряд).

**Цель (Goal):** Результат, который пользователь хочет достичь к определённому сроку. Может быть двух типов:
- *Количественная:* с целевым значением (target). Прогресс измеряется численно (current / target).
- *Бинарная:* без целевого значения. Просто выполнена или нет (completed).

Статус цели вычисляется автоматически: Done, In process, Not completed.

### Отчёт

Бот возвращает пользователю текстовые сообщения с:
- списком привычек и их streak;
- статусами целей и оставшимися днями до дедлайна.

## Use-case

Пользователь должен иметь возможность:

1. создавать привычки с указанием названия;
2. просматривать список своих привычек;
3. отмечать привычку как выполненную за сегодня;
4. получать streak (количество дней подряд);
5. создавать цели с названием, дедлайном и опциональным целевым значением;
6. просматривать список целей со статусом;
7. добавлять прогресс к цели;
8. получать количество дней до дедлайна цели.

## Ограничения области

В этой версии:

- не учитывается пропуск дней (streak обнуляется при пропуске);
- не поддерживается редактирование и удаление привычек и целей;
- не рассматривается многопользовательский доступ к одним данным;
- нет уведомлений и напоминаний;
- нет интеграции с внешними календарями и сервисами.
