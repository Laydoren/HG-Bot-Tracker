# Спецификация проекта HG-Bot-Tracker

## 1. Введение

HG-Bot-Tracker — Telegram-бот для отслеживания привычек и целей. Система позволяет пользователю создавать привычки, отмечать их выполнение, рассчитывать streak (серию дней), а также управлять целями с автоматическим обновлением статуса.

## 2. Функциональные требования

### 2.1 Управление привычками

| Требование | Описание |
|------------|----------|
| Создать привычку | Пользователь может создать привычку, указав её название. Привычка сохраняется в БД с частотой daily. |
| Просмотреть привычки | Пользователь может получить список своих привычек. |
| Отметить выполнение | Пользователь может отметить привычку как выполненную за сегодня. |
| Проверка дублирования | Система не позволяет отметить привычку дважды за один день. |
| Расчёт streak | После отметки выполнения система рассчитывает количество дней подряд. |

### 2.2 Управление целями

| Требование | Описание |
|------------|----------|
| Создать цель | Пользователь может создать цель с названием, дедлайном и опциональным target. |
| Просмотреть цели | Пользователь может получить список целей со статусом и оставшимися днями. |
| Добавить прогресс | Пользователь может добавить прогресс к цели (числовое значение). |
| Автообновление статуса | Система автоматически обновляет статус цели: Done / In process / Not completed. |
| Расчет оставшихся дней | Система показывает количество дней до дедлайна. |
| Фиксация перевыполнения | Если current >= target, цель отмечается как Done. |

### 2.3 Системные требования

| Требование | Описание |
|------------|----------|
| Инициализация БД | При запуске бота создаются таблицы habits, completions, goals. |
| Сохранение данных | Все данные сохраняются в SQLite. |
| Запуск polling | Бот запускает цикл обработки сообщений из Telegram API. |

### 2.4 Пользовательские команды

| Требование | Описание |
|------------|----------|
| Запуск бота | Бот приветствует пользователя по команде /start. |
| Справка | Бот выводит список доступных команд по /help. |

## 3. Команды бота

| Команда | Описание | Параметры |
|---------|----------|-----------|
| `/start` | Приветственное сообщение | — |
| `/help` | Список команд | — |
| `/add_habit <название>` | Создать привычку | Название |
| `/habits` | Список привычек | — |
| `/done <название>` | Отметить выполнение | Название привычки |
| `/add_goal <название; target; deadline>` | Создать цель | Название; target (опц.); deadline |
| `/goals` | Список целей | — |
| `/progress <название; значение>` | Добавить прогресс | Название цели; значение |

## 4. Модели данных

### Habit
- id: int
- user_id: int
- name: str
- frequency: str
- created_at: date

### Completion
- id: int
- habit_id: int
- completed_at: date

### Goal
- id: int
- user_id: int
- title: str
- target: float | None
- current: float
- deadline: date
- completed: bool

## 5. Статусы целей

| Статус | Условие |
|--------|---------|
| Done | target is None и completed=True, или current >= target |
| Not completed | today > deadline и current < target |
| In process | Все остальные случаи |
