# HG-Bot-Tracker

## Overview

**HG-Bot-Tracker** — Telegram-бот для трекинга привычек и целей пользователя.

Он помогает:
- формировать полезные привычки  
- отслеживать регулярность выполнения  
- контролировать прогресс целей  
- автоматически обновлять статус задач  

## Features

### Habits (Привычки)

- создание привычек с параметрами:
  - `name`
  - `frequency`
  - `created_at`
- поддержка разных режимов (daily / weekly и т.д.)

### Completions (Выполнение)

- фиксация выполнения привычек
- привязка к `habit_id`
- хранение даты выполнения (`completed_at`)
- анализ выполненных дней

### Goals (Цели)

- создание целей с параметрами:
  - `title`
  - `target` (опционально)
  - `current`
  - `deadline`
  - `completed`
- два типа целей: количественные (с target) и бинарные (без target, только выполнено/не выполнено)
- автоматическое обновление статуса
- расчёт оставшихся дней до дедлайна
- отслеживание просроченных целей

#### Статусы целей:

- `In process` — в процессе выполнения  
- `Done` — цель достигнута  
- `Not completed` — срок истёк  


## Logic

### is_completed_today()

Функция проверяет, выполнена ли привычка в конкретный день.

**Логика:**
- сравнивает `habit_id`
- проверяет `completed_at`
- возвращает:
  - `True` — если выполнение найдено
  - `False` — если нет

### update_goal_status()

Обновляет статус цели автоматически.

**Правила:**
- если target не указан: `completed = True` → `Done`, иначе → `In process`
- если target указан: `current >= target` → `Done`
- `today > deadline` → `Not completed`
- иначе → `In process`

### is_overdue()

Проверяет, просрочена ли цель (deadline прошёл, а цель не выполнена).

### days_remaining()

Рассчитывает количество дней до дедлайна (отрицательное — просрочка).

## Bot Commands

- `/start` — начать работу
- `/help` — список команд
- `/add_habit <название>` — создать привычку  
- `/habits` — список привычек
- `/done <название>` — отметить выполнение привычки
- `/add_goal <название; target; deadline>` — создать цель  
- `/goals` — список целей
- `/progress <название; значение>` — добавить прогресс цели  

## Benefits

- развитие полезных привычек  
- повышение дисциплины  
- контроль прогресса  
- визуализация достижений  
- улучшение продуктивности

**HG-Bot-Tracker** — это Telegram-бот, который помогает пользователю системно работать над привычками и целями, отслеживая прогресс и автоматизируя контроль выполнения.
