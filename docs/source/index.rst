HG-Bot-Tracker documentation
============================

HG-Bot-Tracker — Telegram-бот для формирования привычек и управления целями.

Система позволяет отслеживать поведение пользователя, фиксировать выполнение привычек и автоматически обновлять статус целей.

В документации описаны доменная модель, логика работы и функциональность проекта.
